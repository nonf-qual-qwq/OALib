# Oralf's Adofai Library


#### (不是Open Access Library)

是基于C#开发的，专门为A Dance of Fire and Ice(又名冰与火之舞 ADOFAI)编写的一个库，简称为OALib

你可以通过写代码来写ADOFAI

比如:

        AdofaiFile input = new AdofaiFile
        {
            FilePath = "D:\\ADOFAI NEW Custom Chart\\测试\\4.adofai"
        };

具体实例可以去OAConsole(也是我的)查看
